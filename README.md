# card-images

A temporary mirror of Pokémon TCG Pocket card images for sets not yet
available from the usual community image sources.

The image files here are repackaged, unmodified, from the MIT-licensed
release artifacts of
[flibustier/pokemon-tcg-pocket-database](https://github.com/flibustier/pokemon-tcg-pocket-database)
(release 2.10.0, `dist.zip`, `images/cards-by-set/`), renamed to a
`images/webp/cards/<set>/<number>.webp` layout. All credit for the
collection and packaging belongs to that project.

The card artwork itself is © The Pokémon Company / Nintendo / Creatures
Inc. / GAME FREAK inc. This mirror exists only to bridge the window
until the images are available from the established community
repositories, and sets are removed as soon as they appear upstream.

If you are a rights holder and want content here removed, open an issue
and it will be taken down promptly.
